# LINE Stamp Tag Helper

LINE Creators Market のスタンプ・絵文字タグを自動設定する Chrome 拡張機能です。

---

## インストール

1. このリポジトリを ZIP でダウンロードして解凍する（または `git clone`）
2. Chrome で `chrome://extensions` を開く
3. 右上の **デベロッパーモード** をオンにする
4. **「パッケージ化されていない拡張機能を読み込む」** をクリック
5. 解凍したフォルダを選択する

---

## 使い方

### 1. タグデータを登録する（ポップアップ）

Chrome ツールバーのアイコンをクリックしてポップアップを開きます。

#### スタンプ / 絵文字の切り替え
ポップアップ右上の **スタンプ / 絵文字** ボタンで対象を切り替えます。
データはそれぞれ独立して保存されます。

#### タグ編集タブ
1. スタンプ数（または絵文字数）を入力して **生成** をクリック
2. 各番号の **「+ タグを選択」** ボタンからタグを選ぶ
   - カテゴリフィルターや検索で絞り込み可能
   - 1つにつき最大9個まで選択
3. **保存** をクリック

#### 入出力タブ
- テキスト（Markdown テーブル / CSV）やファイルを貼り付けてインポート可能
- JSON エクスポート・インポートでデータのバックアップや移行ができる

---

### 2. タグを自動適用する（コンテンツパネル）

LINE Creators Market のタグ編集ページ（URL が `/tag` で終わるページ）を開くと、画面右側にパネルが表示されます。

```
https://creator.line.me/my/{creatorId}/sticker/{stampId}/tag
https://creator.line.me/my/{creatorId}/emoji/{emojiId}/tag
```

#### パネルの操作

| 操作 | 説明 |
|------|------|
| **タグ適用** | 現在のスタンプ/絵文字にタグを適用する |
| **全スタンプに順番に適用** | 登録済みの全番号を順番に処理する |
| **全入れ替え** | 既存タグを全て外してから設定する |
| **不足分追加** | 現在のタグはそのままで不足分だけ追加する |
| **間隔** | タグ1クリックごとの待機時間（ms）。反映されない場合は増やす |

#### 注意
- タグページを開いたままパネルが表示されない場合はページをリロードしてください
- サイトがタグクリック後に自動でタグを追加することがあります。その場合は待機間隔を増やすか、全入れ替えモードをお試しください

## ファイル構成

```
LINE_Tag_Helper/
├── manifest.json     # 拡張機能設定
├── content.js        # タグ自動適用パネル（タグページに注入）
├── content.css       # パネルのスタイル
├── popup.html        # ポップアップ UI
├── popup.js          # ポップアップのロジック・タグデータ管理
├── tagpool.js        # タグプール定義（予備）
├── icon48.png
└── icon128.png
```

## 動作環境

- Google Chrome（最新版推奨）
- LINE Creators Market（`https://creator.line.me`）
